# 员工常见问题 FAQ

本页面汇总了员工日常工作中最常咨询的问题及解答，涵盖人事、行政、财务、IT等各方面。建议先在此搜索，再联系相关负责人。

---

## 一、人事相关

### Q1：我的年假有几天？怎么查？
**A**：年假天数根据累计工作年限计算：
- 满1年不满10年 → 5天
- 满10年不满20年 → 10天
- 满20年以上 → 15天

查询路径：OA系统 → 我的考勤 → 年假余额。

### Q2：年假可以跨年休吗？
**A**：当年年假须在次年3月31日前休完，逾期自动作废。特殊情况（如项目关键期）经部门负责人和HR批准，可顺延至6月30日。

### Q3：怎么请病假？需要什么材料？
**A**：请病假流程：
1. OA系统提交《请假申请单》，类型选择「病假」。
2. 上传二级及以上医院出具的 **诊断证明 + 病历**。
3. 部门负责人审批 → HR备案。
4. 病假工资按当地最低工资标准的80%发放。

### Q4：事假和年假有什么区别？
**A**：
- **年假**：带薪，须在规定时间内休完。
- **事假**：无薪，全年累计不得超过15天，需提前1天申请。

### Q5：产假可以提前休吗？
**A**：产假可提前15天开始休，需提交《产假申请》及医院出具的预产期证明。产假期间须保持通讯畅通，以便必要时的业务沟通。

### Q6：离职时未休年假怎么算？
**A**：按日工资的 **300%** 折算现金补偿，计算公式为：  
> （未休天数 × 月薪 ÷ 21.75）× 300%

### Q7：社保和公积金什么时候开始缴纳？
**A**：入职当月即开始缴纳社保和公积金（15号前入职的当月缴纳，15号后入职的下月缴纳）。个人承担部分从工资中扣除。

### Q8：如何打印收入证明/在职证明？
**A**：OA系统 → 人事服务 → 证明开具 → 选择类型 → 填写用途 → 提交审批。审批通过后，电子版发送至邮箱，纸质版可到HR部门领取。

## 二、考勤与加班

### Q9：我忘记打卡了怎么办？
**A**：在 **2个工作日内** 在OA系统中提交《补卡申请》，说明原因，部门负责人审批后生效。每月补卡次数超过3次会影响绩效评分。

### Q10：迟到多久算旷工？
**A**：
- 迟到 > 1小时：按旷工半天处理。
- 迟到 > 15分钟且 ≤ 1小时：按事假半天处理。

### Q11：加班怎么申请？加班费怎么算？
**A**：
1. 加班须提前在OA提交《加班申请单》，紧急情况事后2日内补单。
2. 加班费计算：
   - 工作日加班（18:00后）：1.5倍时薪
   - 休息日加班：2倍时薪 或 1:1调休
   - 法定节假日加班：3倍时薪

### Q12：调休有有效期吗？
**A**：调休须在加班发生之日起 **6个月内** 使用完毕，逾期视为放弃。

### Q13：外勤/出差怎么打卡？
**A**：出差/外勤期间，通过「钉钉/飞书」外勤打卡功能进行定位打卡，或在OA系统中提交《外勤/出差申请单》审批通过后，视为正常出勤。

## 三、报销与财务

### Q14：报销需要哪些材料？
**A**：报销必备材料：
- 发票原件（增值税普通发票或专用发票）
- 消费明细单/小票（如为餐饮或住宿）
- 审批通过的《费用报销单》（OA系统生成）
- 特殊情况需附加说明（如超标原因等）

### Q15：报销多久能到账？
**A**：审批流程通过后，**5个工作日内** 打入员工工资卡。

### Q16：电子发票怎么报销？
**A**：将电子发票打印出来，附在报销单后，同时在OA上传PDF或OFD文件。打印件须清晰完整，二维码和发票号码可见。

### Q17：哪些费用不能报销？
**A**：
- 私人消费（非因公产生的费用）
- 发票抬头错误或信息不全
- 超过预算且未经审批的费用
- 无有效发票或票据不完整的费用
- 开具超过30天的发票

### Q18：出差餐补需要发票吗？
**A**：出差餐补（¥80/天）按出差天数定额发放，**不需要** 发票。住宿和交通费需凭票报销。

### Q19：工资什么时候发放？
**A**：每月 **10号** 发放上月工资（遇节假日顺延）。工资条可在OA系统中查看下载。

## 四、IT与系统

### Q20：如何重置OA/邮箱密码？
**A**：以下三种方式任选：
1. 登录页点击「忘记密码」，通过手机验证码重置。
2. 联系IT部门（王工，分机7701）。
3. 在企业微信/钉钉中搜索「IT助手」自助重置。

### Q21：公司WiFi密码是多少？
**A**：
- WiFi名称：Company-Office
- 密码：每季度更新一次，请在OA公告或IT部门查看最新密码。
- 访客网络：Guest-Office（密码咨询前台）。

### Q22：怎么安装公司内部软件？
**A**：公司内部软件（如VPN、OA客户端、杀毒软件等）可在 **内部软件中心** 下载安装：
> 地址：https://soft.company.com  
> 用户名：个人工号 / 密码：OA密码

### Q23：设备故障怎么报修？
**A**：OA系统 → IT服务 → 设备报修 → 填写故障描述 → 提交。IT部门会在 **2小时内** 响应。

### Q24：离职时IT交接需要哪些步骤？
**A**：
1. 提交《IT交接单》，填写账号和设备信息。
2. 归还全部设备（电脑、显示器、配件等）。
3. 数据迁移：将个人工作文件转移至部门共享盘。
4. IT部门确认后签字。

### Q25：可以使用个人设备办公吗？
**A**：原则上不建议使用个人设备办公，如确有需要，须向IT部门申请并安装公司安全管控软件（MDM），且自行承担数据安全责任。

## 五、行政与后勤

### Q26：办公用品怎么申领？
**A**：OA系统 → 行政服务 → 办公用品申领 → 选择所需物品 → 提交 → 行政部配送/前台自取。

### Q27：出差怎么订机票/酒店？
**A**：通过公司合作的商旅平台预订：
- 平台地址：https://travel.company.com
- 使用公司统一支付，无需个人垫付。
- 若因特殊情况需自行预订，须在出差申请中说明，并按标准凭票报销。

### Q28：快递怎么寄？
**A**：
- 公司合作的快递：顺丰、EMS（寄件码在前台领取）。
- 寄件流程：填写快递单 → 联系前台称重 → 录入寄件系统 → 寄出。
- 个人快递不享受公司协议价。

### Q29：健身房/休息区怎么使用？
**A**：
- 健身房：工作日 07:00-22:00 开放，刷工牌进入。
- 休息区：24小时开放，设有按摩椅、咖啡机、茶水间。
- 每月最后一周周五为「健康日」，公司组织集体健身活动。

### Q30：公司有食堂/午餐补贴吗？
**A**：
- 公司提供 **午餐补贴 ¥20/天**，随工资发放。
- 办公室设有茶水间，提供咖啡、茶饮、水果（每日限量）。

## 六、公司政策与文化

### Q31：公司有哪些福利？
**A**：
- 五险一金（足额缴纳）
- 补充商业保险（员工及子女）
- 年度体检（1次/年）
- 节日福利（春节、中秋、端午等）
- 生日礼金（¥200/人）
- 团建经费（每人 ¥1500/年）
- 学习补贴（每人 ¥2000/年，用于购书/培训）
- 弹性工作制（核心时间段 10:00-16:00 须在岗）

### Q32：公司禁止哪些行为？
**A**：
- 泄露公司机密信息
- 工作时间从事与工作无关的活动（如炒股、游戏等）
- 对同事进行骚扰、歧视或不当言行
- 违规操作造成安全隐患
- 违反廉洁规定（收受回扣、利益输送等）

### Q33：内部沟通使用什么工具？
**A**：根据部门习惯，使用 **钉钉** 或 **飞书**（大部分部门使用飞书）。公司通讯录可在飞书/钉钉中直接查找。

### Q34：公司有内推奖励吗？
**A**：有。成功推荐人才入职：
- 普通员工：奖励 ¥1,000
- 技术骨干/管理岗：奖励 ¥2,000~¥5,000
- 年度内推冠军另有额外奖励。

### Q35：如何反馈意见或投诉？
**A**：
- 匿名方式：公司信箱（设在茶水间）、匿名问卷链接
- 实名方式：直接联系HR部门或发送邮件至 hr@company.com
- 所有反馈均在 **7个工作日内** 给予回应。

### Q36：加班有晚餐补贴吗？
**A**：工作日加班超过 **20:00**，公司提供晚餐补贴 ¥30/人，通过「饿了么企业版」或「美团企业版」下单，无需个人垫付。

### Q37：节假日值班有额外补贴吗？
**A**：法定节假日值班按 **日工资的300%** 计算；休息日值班优先安排调休，无法调休的按 **日工资的200%** 计算。
