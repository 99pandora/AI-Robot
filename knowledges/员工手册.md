- # 员工手册

  ## 第一章 总则

  本手册旨在帮助全体员工了解公司的各项规章制度，明确员工的权利与义务，营造公平、高效、和谐的工作环境。本手册适用于公司全体正式员工、试用期员工及实习生。

  ---

  ## 第二章 考勤管理制度

  ### 2.1 工作时间

  | 类别 | 时间          |
  | ---- | ------------- |
  | 上午 | 09:00 - 12:00 |
  | 下午 | 13:30 - 18:00 |
  | 午休 | 12:00 - 13:30 |

  公司实行每周五天工作制（周一至周五），周六、周日为休息日。

  ### 2.2 打卡规定

  1. 员工每日需打卡 **2次**（上班、下班），部分岗位根据实际安排执行。
  2. 因公外出或出差无法打卡时，需提前在OA系统中提交《外勤/出差申请单》，经审批通过后视为正常出勤。
  3. 忘打卡需在 **2个工作日内** 提交《补卡申请》，经部门负责人审批后生效。每月补卡次数超过 **3次** 将影响当月绩效评分。

  ### 2.3 迟到/早退

  | 迟到/早退时长    | 处理方式                          |
  | ---------------- | --------------------------------- |
  | ≤ 15分钟         | 口头提醒，月度累计达3次计旷工半天 |
  | 15分钟 ~ 1小时   | 按事假半天处理                    |
  | > 1小时          | 按旷工半天处理                    |
  | 未经批准擅自离岗 | 按旷工处理                        |

  ### 2.4 旷工

  1. 无故缺勤、未经批准擅自休假或超假不归者，按旷工处理。
  2. 连续旷工 **3天** 或年度累计旷工 **5天** 以上，公司有权解除劳动合同。

  ## 第三章 休假管理制度

  ### 3.1 法定节假日

  按国家规定执行，包括元旦、春节、清明节、劳动节、端午节、中秋节、国庆节等。

  ### 3.2 年休假

  | 累计工作年限   | 年假天数 |
  | -------------- | -------- |
  | 满1年不满10年  | 5天      |
  | 满10年不满20年 | 10天     |
  | 满20年以上     | 15天     |

  **年假使用规则：**
  - 年假以 **半天** 为单位申请和使用。
  - 当年年假须在 **次年3月31日** 前休完，逾期未休视为自动放弃（特殊情况经批准可顺延）。
  - 离职时未休年假按日工资 **300%** 折算补偿。

  ### 3.3 病假

  1. 员工因病需休息治疗，须提供 **二级及以上医院** 开具的病假证明。
  2. 病假工资按 **当地最低工资标准的80%** 发放。
  3. 连续病假超过 **30天**，公司有权根据实际情况调整岗位或协商处理。

  ### 3.4 事假

  1. 员工因私事需请假，须提前 **1个工作日** 在OA系统中申请。
  2. 事假为无薪假，按月工资基数扣除当日薪资。
  3. 全年事假累计不得超过 **15天**，超出部分不予批准。

  ### 3.5 婚假

  1. 符合法定结婚年龄的员工，享有 **3天** 婚假（不含法定节假日）。
  2. 婚假须在领取结婚证之日起 **6个月内** 一次性休完。
  3. 再婚员工同样享有婚假待遇。

  ### 3.6 产假及陪产假

  | 类别       | 天数                               | 备注                 |
  | ---------- | ---------------------------------- | -------------------- |
  | 产假       | 98天（难产+15天，多胞胎每胎+15天） | 含产前15天           |
  | 男方陪产假 | 15天                               | 须在分娩后30天内休完 |
  | 哺乳假     | 每天1小时（至婴儿满1周岁）         | 可协商集中使用       |

  ### 3.7 丧假

  | 亲属关系                   | 天数 |
  | -------------------------- | ---- |
  | 父母、配偶、子女           | 3天  |
  | 祖父母、兄弟姐妹、配偶父母 | 1天  |

  ## 第四章 加班管理制度

  ### 4.1 加班定义

  员工在规定工作时间以外，因工作需要经上级审批安排的工作时间，称为加班。

  ### 4.2 加班申请

  1. 加班须提前在OA系统中提交《加班申请单》，说明事由及预计时长。
  2. **紧急情况** 可先口头报备，事后 **2个工作日内** 补办手续。
  3. 未经审批的加班，公司不予认可。

  ### 4.3 加班补偿

  | 加班时段              | 补偿方式                                       |
  | --------------------- | ---------------------------------------------- |
  | 工作日加班（18:00后） | 按 **1.5倍** 时薪计算加班费，或选择调休（1:1） |
  | 休息日加班            | 安排调休（1:1），无法调休按 **2倍** 时薪计算   |
  | 法定节假日加班        | 按 **3倍** 时薪计算加班费，不安排调休          |

  4. 每月加班时长上限为 **36小时**，全年累计不超过 **432小时**。

  ## 第五章 出差管理制度

  ### 5.1 出差申请

  1. 员工出差须提前填写《出差申请单》，明确出差地点、事由、时间及预算。
  2. 出差审批流程：部门负责人 → 分管领导 → 财务部（涉及费用预支时）。

  ### 5.2 出差费用标准

  | 项目     | 标准                                                 | 说明                         |
  | -------- | ---------------------------------------------------- | ---------------------------- |
  | 住宿费   | 一线城市 ¥500/晚；二线城市 ¥350/晚；三线城市 ¥250/晚 | 凭票实报实销，超出部分自理   |
  | 餐补     | ¥80/天                                               | 按实际出差天数计算，无需发票 |
  | 交通费   | 高铁二等座/飞机经济舱                                | 凭票报销，特殊情况需提前审批 |
  | 市内交通 | ¥50/天                                               | 凭票实报实销                 |

  ### 5.3 出差报销

  1. 出差归来后 **5个工作日内** 提交报销申请。
  2. 住宿、交通票据须真实完整，电子发票需打印并附上验证码。
  3. 超标费用须提前申请，否则不予报销。

  ## 第六章 报销管理制度

  ### 6.1 报销流程

  1. 员工在OA系统中填写《费用报销单》。
  2. 上传发票及附件 → 部门负责人审批 → 财务审核 → 出纳付款。
  3. 报销周期：审批通过后 **5个工作日内** 到账。

  ### 6.2 发票要求

  1. 发票须为 **增值税普通发票** 或 **增值税专用发票**。
  2. 发票内容须与实际消费一致，抬头为公司全称及纳税人识别号。
  3. 发票须在 **开具后30天内** 提交报销，逾期不予受理。

  ### 6.3 不予报销情形

  - 发票信息不全或虚假
  - 因私消费
  - 超出预算且未经审批的费用
  - 无审批流程的支出
