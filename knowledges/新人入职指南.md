  - **报到地点**：公司前台（联系人：HR 张女士 / 电话：010-8888-6666）

  | 系统               | 用途                                       | 初始密码获取方式 |

  ### 3.2 密码管理

  - 首次登录后请立即修改初始密码。
  - 密码须包含 **大写字母 + 小写字母 + 数字 + 特殊符号**，长度不少于 **8位**。
  - 每 **90天** 强制更换密码。
  - 严禁将账号密码告知他人或记录在非加密位置。

  ## 四、设备申领

  ### 4.1 设备类型

  根据岗位需求，你可申领以下设备：

  | 岗位类型  | 标配设备                      | 可选配件             |
  | --------- | ----------------------------- | -------------------- |
  | 研发/技术 | 笔记本电脑（Win/Mac）、扩展坞 | 外接显示器、机械键盘 |
  | 设计      | 笔记本电脑（Mac）、手绘板     | 外接显示器、校准色仪 |
  | 运营/市场 | 笔记本电脑（Win）、手机测试机 | 移动WiFi             |
  | 行政/财务 | 台式机或笔记本                | 打印机权限           |

  ### 4.2 申领流程

  1. 在OA系统中填写《设备申领表》。
  2. 部门负责人审批 → IT部门审批。
  3. 审批通过后，前往IT部门领取设备（入职当天或次日）。
  4. 签署《设备领用确认单》，确认设备完好。

  ### 4.3 设备使用规范

  - 设备仅限本人使用，不得转借他人。
  - 不得私自安装未经授权的软件。
  - 设备损坏或故障应及时联系IT部门报修。
  - 离职时须归还全部设备，丢失或损坏需按原价赔偿。

  ## 五、培训流程

  ### 5.1 培训体系

  新人培训分为三个阶段：

  | 阶段     | 时间          | 内容                           | 考核方式 |
  | -------- | ------------- | ------------------------------ | -------- |
  | 入职培训 | 入职第1天     | 公司文化、制度、安全、系统操作 | 在线测试 |
  | 部门培训 | 入职第1周     | 部门职责、业务流程、岗位技能   | 导师评估 |
  | 岗位培训 | 入职第1-3个月 | 深度业务培训、实战项目参与     | 转正答辩 |

  ### 5.2 导师制

  - 每位新人都将配备一名 **入职导师**（部门资深员工）。
  - 导师负责指导日常工作、解答疑问、帮助融入团队。
  - 每周至少与导师进行 **1次** 1对1沟通（建议每周五下午）。

  ### 5.3 在线学习资源

  | 平台     | 内容                         | 地址                 |
  | -------- | ---------------------------- | -------------------- |
  | 内部Wiki | 产品文档、技术规范、流程手册 | wiki.company.com     |
  | 培训系统 | 视频课程、在线测试           | training.company.com |
  | 知识库   | 常见问题、最佳实践           | kb.company.com       |

  ### 5.4 转正流程

  - 试用期一般为 **3个月**，表现优异可提前转正。
  - 转正需完成以下流程：
    1. 提交《转正申请表》（提前2周）。
    2. 部门组织转正答辩/评估。
    3. HR审核 → 分管领导审批。
    4. 通过后签订《转正确认书》。

  ## 七、新人心态建议

  1. **多问**：刚入职不了解是正常的，遇到问题及时向导师或同事请教。
  2. **多记**：重要流程、系统操作建议做好笔记（可用内部Wiki记录）。

  4. **多融入**：积极参与部门团建、午餐聚会，建立良好人际关系。
